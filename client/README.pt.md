### Prerequisites

* Flutter SDK installed locally
* For the intended experience, a connected mobile device or emulator

### 1. Instalar as Dependências
Navegue até o diretório do frontend e baixe as dependências do projeto:

```bash
flutter pub get
```

### 2. Executar o Aplicativo
Compile e execute o programa, escolhendo seu dispositivo de preferência:
```bash
flutter run
```
